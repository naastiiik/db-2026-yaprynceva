# База данных фитнес-клуба

## Описание проекта

Предметная область:
База данных для управления фитнес-клубом: учёт клиентов, расписание тренировок, загрузка залов, работа тренеров.

Решаемая проблема:
Система решает задачу учёта посещаемости и распределения нагрузки. Она позволяет вести запись клиентов на тренировки, отслеживать загрузку залов и тренеров, а также собирать оценки клиентов о качестве занятий.
